# Jarvis Dota 2: Голосовой помощник для Kez & Invoker (Umbrella)

Голосовой ассистент с искусственным интеллектом (быстрый Whisper + Silero VAD) для Dota 2 под Umbrella. Называешь спелл, предмет или комбо голосом — скрипт сам мгновенно переключает стойки, инвокает и применяет способности в курсор или цель без задержек.

---

## ⚡ Что нового в этой версии (Оптимизация и Kez)
1. **Поддержка нового героя Kez (Кез):**
   - Автоматический контроль стоек **Катана (Katana)** и **Сай (Sai)** через способность *Switch Discipline*.
   - Если нужный спелл находится в другой стойке — Jarvis сам мгновенно переключает оружие и кастует способность.
   - Спеллы в курсор: *Echo Slash*, *Grappling Claw*, *Talon Toss*.
   - Мгновенные спеллы: *Raptor Dance*, *Falcon Rush*, *Shodo Sai (Parry)*, *Raven's Veil*.
2. **Мгновенный отклик и сверхнизкая задержка (Latency Fix):**
   - Исправлена критическая ошибка fallback на CPU на видеокартах Pascal (GTX 1050 / 1060 / 1070 / 1080) и GTX 1650: теперь Whisper гарантированно работает на **CUDA с `int8_float32`** (скорость распознавания выросла в **15–20 раз**, отклик ~70–120 мс вместо 3–4 секунд).
   - Адаптивное окно энкодера Whisper (10 секунд вместо 30) ускоряет прогон коротких фраз в 2–3 раза.
   - Агрессивные тайминги детектора речи Silero VAD: `early_silence_ms = 60` мс (срабатывание команды сразу после завершения слова), `vad_silence_ms = 180` мс, `partial_interval_ms = 180` мс.

## 📥 Установка

1. **Lua-скрипты** скопируй в папку `scripts` Umbrella (обычно `C:\uc.zone\scripts\`):
   - `kez_jarvis.lua` — для игры за Kez
   - `invoker_jarvis.lua` — для игры за Invoker
   Перезагрузи скрипты в меню Umbrella.
2. **`Jarvis.exe`** запусти. Значок появится в трее Windows (возле часов).
   - *Первый запуск:* ассистент один раз автоматически докачивает модель распознавания (~0.5 ГБ).
3. **В игре включи скрипт:**
   - Для Kez: `Heroes → Kez → Jarvis → «Включить»` (или во вкладке `Scripts → Jarvis Kez`)
   - Для Invoker: `Heroes → Invoker → Jarvis → «Включить»`

> [!TIP]
> **Микрофон:** Jarvis по умолчанию использует системный микрофон Windows. Выбрать конкретный микрофон можно в меню значка Jarvis в трее правой кнопкой мыши. Рекомендуется играть в наушниках, чтобы звук игры не глушил распознавание.

## 🎤 Голосовые команды

Сначала обращение: **«Джарвис, [команда]»**. После обращения Jarvis слушает в течение 10 секунд без повторного обращения. Можно называть несколько команд подряд в одной фразе (например: *«блинк раптор»* или *«бкб вуаль фалькон»*).

### ⚔️ Способности Kez (Кез)

| Скажи | Способность | Что произойдет |
|---|---|---|
| **«эхо слэш»**, **«эхо»**, **«слэш»** | Echo Slash (Q, Катана) | Удар катаной в сторону курсора |
| **«коготь»**, **«крюк»**, **«грэпплинг»** | Grappling Claw (W, Катана) | Крюк-кошка в цель у курсора |
| **«кадзурай»**, **«катана»** | Kazurai Katana (E, Катана) | Пассивка/активка катаны |
| **«раптор»**, **«раптор дэнс»**, **«танец»** | Raptor Dance (R, Катана) | Ультимейт катаны (радиальные удары) |
| **«фалькон»**, **«фалькон раш»**, **«сокол»** | Falcon Rush (Q, Сай) | Рывок сокола (атаки с рывками) |
| **«талон тосс»**, **«талон»**, **«бросок»**, **«дротик»** | Talon Toss (W, Сай) | Бросок кинжала в курсор со сайленсом |
| **«парирование»**, **«парируй»**, **«шодо»** | Shodo Sai (E, Сай) | Парирование сай / метка |
| **«вуаль»**, **«дым»**, **«рейвен»**, **«ворон»** | Raven's Veil (R, Сай) | Ультимейт сай (дымовая завеса) |
| **«стойка»**, **«смени оружие»**, **«смени стойку»**, **«свитч»** | Switch Discipline (D) | Переключить стойку Катана ↔ Сай |

*Примечание:* Если вы находитесь в стойке Сай и говорите команду Катаны (например, *«раптор»*), бот автоматически нажимает смену стойки и применяет способность без задержки.

### 🧙‍♂️ Способности Invoker (Инвокер)

| Скажи | Что произойдет |
|---|---|
| **«санстрайк»**, **«метеор»**, **«колд снэп»**, **«торнадо»**, **«эмп»**, **«алакрити»**, **«гост волк»**, **«айс волл»**, **«форджи»**, **«бласт»** | Вызвать нужные сферы, нажать Invoke и применить спелл в курсор/цель |
| **«скастуй метеор»**, **«инвокни бласт»** | Только вызвать спелл в свободный слот, не применяя его |
| **«катаклизм»** | Sun Strike с двойным нажатием (катаклизм) |
| **«алакрити на союзника»** | Применить Alacrity на героя под курсором |
| **«квас»**, **«векс»**, **«экзорт»** | Выставить 3 сферы (QQQ, WWW, EEE) и запомнить стойку возврата |
| **«качай экзорт»**, **«качай первый/второй»** | Прокачать способность |
| **«комбо 1» … «комбо 12»** | Запустить комбо из сборщика комбо Umbrella |
| **«комбо динамик»** | Запустить динамическое комбо Umbrella |

---

### ⚙️ Системные команды бота

- **«мут»** / **«выключи микрофон»** — временно отключить распознавание команд (слышит только команду *«включись»*).
- **«включись»** / **«размуть»** — снова слушать команды.
- **«спи»** — перейти в режим ожидания обращения *«Джарвис»*.
- **«выключись»** — полностью закрыть ассистента.

## 🛠️ Сборка из исходников

Если вы хотите собрать бинарник самостоятельно:
```bash
cd voice
pip install -r requirements.txt pyinstaller pytest
pytest -q
python -m PyInstaller --noconfirm --onefile --windowed --name Jarvis --paths . \
  --add-data "config.yaml;." \
  --collect-all faster_whisper --collect-all ctranslate2 --collect-all onnxruntime \
  --collect-data _sounddevice_data \
  --exclude-module PySide6.QtQml --exclude-module PySide6.QtQuick \
  --exclude-module PySide6.QtNetwork --exclude-module PySide6.QtOpenGL \
  --exclude-module tkinter --exclude-module matplotlib \
  jarvis_main.py
```
Готовый `Jarvis.exe` появится в папке `voice/dist/`.
